Title: 🌸 Ferns and Petals Sales Dashboard

About the Project
This project is an interactive Excel dashboard created to analyze the sales data of Ferns and Petals (a gifting company). The goal was to uncover business insights regarding revenue, customer buying behavior, and top-performing regions.

Tools & Skills Used

Microsoft Excel

PivotTables & PivotCharts

Data Modeling (Relational Data)

Slicers (Interactive Filtering)

Dashboard Design

Key Metrics Analyzed

Sales by Occasion: Identified which festivals drive the most revenue.

Monthly Trend: Analyzed sales performance over the months to find peak periods.

Top 10 Cities: Discovered which cities contribute the most to total sales.
